# Sistema de Ventas - TecnoStore

¡Hola, profe! Este es mi proyecto final de programación estructurada en Java. Desarrollé un sistema interactivo para la gestión de inventarios y facturación de una tienda de tecnología.

## Temas Aplicados en el Código
* **Vectores:** Utilizados para el manejo y almacenamiento de los nombres de los productos.
* **Matrices:** Implementadas para estructurar los datos numéricos (Códigos, Precios, Stock inicial y Unidades vendidas).
* **Ciclos y Estructuras de Control:** Uso de `do-while`, `for` e `if` para controlar el flujo del menú y las validaciones de entrada de datos.
* **Modularidad:** El código está organizado de manera limpia mediante funciones/métodos independientes.

## Historial de Desarrollo (Git)
El proyecto se desarrolló aplicando buenas prácticas de control de versiones con Git, realizando commits incrementales para evidenciar el avance paso a paso:
1. Estructura base y matriz de datos.
2. Funciones de visualización y validación por consola.
3. Lógica de facturación de ventas y reportes de caja.
